# Keyboard shortcuts

PadForge follows the familiar Notepad++/desktop editor conventions.

On macOS, the `Ctrl` modifier shown here uses the Command (`⌘`) key.

## Files

| Shortcut | Action |
| --- | --- |
| `Ctrl+N` | New document |
| `Ctrl+O` | Open file |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save as |
| `Ctrl+Alt+S` | Save a copy as |
| `Ctrl+W` | Close current document |
| `Ctrl+P` | Print |
| `Ctrl+Q` | Quit |

## Editing

| Shortcut | Action |
| --- | --- |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` / `Ctrl+Y` | Redo |
| `Ctrl+X` | Cut |
| `Ctrl+C` | Copy |
| `Ctrl+V` | Paste |
| `Ctrl+A` | Select all |
| `Ctrl+D` | Duplicate current line |
| `Ctrl+Shift+C` | Toggle line comment |
| `Ctrl+Shift+B` | Toggle block comment |
| `Ctrl+Alt+C` | Column editor |
| `Ctrl+G` | Go to line |
| `Ctrl+Space` | Word completion |
| `Ctrl+Enter` | Function/symbol completion |
| `F7` | Next difference (compare) |
| `Shift+F7` | Previous difference (compare) |

## Search

| Shortcut | Action |
| --- | --- |
| `Ctrl+F` | Find |
| `Enter` (in Find field) | Find next |
| `Ctrl+H` | Replace |
| `Ctrl+Shift+F` | Find in files |

## Bookmarks

| Shortcut | Action |
| --- | --- |
| `Ctrl+F2` | Toggle bookmark on the current line |
| `F2` | Next bookmark |
| `Shift+F2` | Previous bookmark |

## View

| Shortcut | Action |
| --- | --- |
| `Ctrl++` | Zoom in |
| `Ctrl+-` | Zoom out |
| `Ctrl+0` (Reset Zoom) | Reset zoom |
| `F11` | Full screen |

## Window

| Shortcut | Action |
| --- | --- |
| `Ctrl+Tab` | Next tab |
| `Ctrl+Shift+Tab` | Previous tab |
| `Alt+1`..`Alt+9` | Jump to document 1..9 |
| `Ctrl+Alt+D` | Detach current tab to floating window |

> Right-click a tab for the tab context menu (close others/left/right/all, save,
> reload, rename, copy path, open containing folder, move to other view);
> **middle-click** a tab to close it. **Sort Tabs** (by name or path) is in the
> Window menu.

## Tools

| Shortcut | Action |
| --- | --- |
| `F5` | Run command... |
| `Ctrl+,` (Preferences) | Open preferences |

> The **Script Console** input runs on `Enter`, with `Up`/`Down` to cycle
> through command history.

> In the **Function List** dock, `Enter` or double-click jumps to the selected
> symbol; in the **Character Map**, double-click inserts the selected glyph at
> the caret.

> Tip: every menu entry that has a shortcut also shows it next to the item, so
> you can discover the full list from within the application.
